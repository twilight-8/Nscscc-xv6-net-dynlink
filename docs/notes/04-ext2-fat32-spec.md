# 04 ext2 与 fat32 规范要点精读

本篇按实现后端时实际用到的最小集合记录两个文件系统格式的要点。

## ext2

- **布局**：超级块（偏移 1024）→ 块组描述符 → 块位图 / inode 位图 / inode 表 → 数据区。单块组镜像（4096 块 × 1KiB）足够赛题使用。
- **inode（dinode）**：`i_mode`（类型+权限）、`i_links_count`、`i_size`、`i_block[15]`（12 直接 + 1 单间接 + 1 双间接 + 1 三间接）、`i_blocks`（按 512B 扇区计，**含间接表本身**——sync 时要数进去，否则 e2fsck 校验不一致）。
- **目录项**：`inode / rec_len / name_len / name`，`rec_len` 4 字节对齐，遍历与删除（合并前驱 rec_len）都要按它对齐处理。
- **位图分配**：扫描上界必须钳到 `s_blocks_count`/`s_inodes_count`，不能信任“组内位数”——越界位在 mke2fs 镜像里被填 1，但在其他工具生成的镜像上不一定（B4）。
- **双重间接**：`i_block[13]` 指向外层表，外层表每项指向一张内层表；分配要按需建表并清零，释放要逐层回收。

## fat32

- **布局**：BPB（0 扇区）→ 保留区 → FAT 表（×2）→ 数据区；簇号从 2 起，数据区起始扇区 = 保留 + FAT 数量 × FAT 大小。
- **FAT 链**：每簇一个 32 位表项（取低 28 位），0=空闲，≥0x0FFFFFF8=链尾；分配与释放是对 FAT 的读改写——无锁就会在 SMP 下双分配（C1）。
- **8.3 目录项**（32 字节）：名字 11 字节（大写、空格填充）、属性、首簇（高低 16 位拼接）、尺寸；删除标记是把首字节改成 0xE5。
- **LFN 长名链**：属性 0x0F 的伪目录项，**倒序存储**在短名项之前；每片 13 个 UTF-16LE 字符（偏移 1/14/28 三段）；序号的 0x40 位标记逻辑最后一片；校验和（短名 11 字节的滚动和）把链和短名项绑定——校验不过就必须忽略整条链，否则会张冠李戴。

## 两个后端的公共实现约定

- 块访问统一经 `block.c` 的字节偏移接口；元数据写立即落盘（无日志，属明确取舍）。
- `iget` 缓存语义与 xv6 一致：仅 `valid==0` 时从磁盘填充。
- unlink 只减链接数，释放延迟到最后一次 close。
