# tests

> 本目录对源码测试进行详细记录

## 目录结构说明

该目录由多个子目录组成，每个子目录对应一个测试样例
每个子目录内分以下五部分：

- `README.md`：说明测试目的、环境和简要结果记录
- `src/`：测试源码
- `run.sh`：可复现的构建和运行命令
- `logs/`：测试日志
- `analysis.md`：对本次测试结果的分析

以一个名为 `test1/` 的测试样例为例，其内部结构一般如此：

```text

test1/
├── src/
├── run.sh
├── logs/
└── analysis.md

```
